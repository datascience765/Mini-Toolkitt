# Mini Toolkit

Free online text tools that run in your browser: word counter, case converter and password generator.
Plain HTML, CSS and JavaScript. No build step.

## Deploy on GitHub Pages
1. Upload all files to a GitHub repository named `mini-toolkit`.
2. Go to Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
3. Your site will be live at `https://USERNAME.github.io/mini-toolkit/`.

Replace `USERNAME` in `index.html`, the tool pages, `sitemap.xml` and `robots.txt` with your GitHub username.
